# Ollama for Local AI

## Install Ollama on Windows
1. Download Ollama 
   - [https://ollama.com/download](https://ollama.com/download)
2. Install Ollama 
    - Run the downloaded installer
3. Browse Ollama Models
   - [https://ollama.com/search](https://ollama.com/search)


## Run an Ollama Model in CLI
1. Pull a Model 
   - `ollama pull granite4:1b`
2. Run a Model 
   - `ollama run granite4:1b`   (in CLI)
3. Exit Ollama CLI 
   - `/exit`
* **NOTE:** *Running a non-installed model will automatically* `pull` *first!*


## Install Ollama in Python
1. Install Ollama 
   - `python -m pip install ollama`
